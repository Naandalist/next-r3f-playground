# next-r3f-playground

Practice playground for **Next.js App Router + TypeScript + React Three Fiber**.

This repo starts as a clean Next.js scaffold. 3D / R3F arrives in later commits — read `git log --reverse` as the curriculum once docs land.

## Stack (so far)

- Next.js (App Router)
- TypeScript
- Tailwind CSS
- ESLint

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).
